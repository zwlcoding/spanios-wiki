# 分类标签

技能内部使用五个标准分类角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 技能内部角色 | 本仓库标签 | 含义 |
|-------------|-----------|------|
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，AI 可直接接手 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

当技能提到某个角色（例如"应用 AFK-ready 分类标签"）时，请使用上表中的对应标签字符串。

如需调整标签命名，直接修改右侧列以匹配你实际使用的词表。
